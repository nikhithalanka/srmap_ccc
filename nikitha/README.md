# Student Registration Management System (SRMS)

A C-based Student Registration Management System that allows users to manage student information including login details and academic records.

## Features

- Student registration and login
- Student information management
- Secure credential handling
- Data persistence with file storage

## Files

- `SRMS.C` - Main C program for the student management system
- `LoginDetails.txt` - Stores user login credentials
- `StudentInfo.txt` - Stores student information records
- `SRMS.exe` - Compiled executable

## Prerequisites

- C compiler (GCC, MinGW, or MSVC)
- Windows OS (for .exe file)

## Compilation

```bash
gcc -o SRMS.exe SRMS.C
```

## Usage

Run the compiled executable:

```bash
./SRMS.exe
```

Follow the on-screen prompts to:
1. Register new students
2. Login with existing credentials
3. Manage student records
